# 面向工具调用的智能体自动化评测与故障诊断平台

**Agent Tool-Calling Automated Evaluation and Fault Diagnosis Platform**

## 1. 项目简介

本项目是一个面向大语言模型智能体（AI Agent）工具调用场景的自动化评测与故障诊断平台，旨在解决智能体在工具调用过程中存在的工具选择错误、参数生成不正确、工具执行超时、返回结果异常以及任务执行失败等问题。

平台通过构建可控的模拟工具环境，模拟正常执行、工具超时、空结果、参数错误和工具执行失败等场景，对智能体的工具调用过程进行自动化测试。

系统记录智能体从任务接收到最终结果生成的完整执行轨迹，基于预设评测指标分析智能体的工具调用能力，并通过故障分类机制识别执行失败的原因。

此外，平台支持不同提示词配置和纠错策略的对比实验，分析不同故障类型对智能体任务完成率的影响，最终生成可复现的评测报告，为智能体工具调用能力评估和可靠性优化提供实验依据。

## 2. 项目目标

本项目主要实现以下目标：

- 构建具有工具调用能力的基础智能体。
- 实现可配置的模拟工具环境和故障注入机制。
- 实现测试任务管理和自动化执行。
- 记录智能体完整的工具调用轨迹。
- 设计工具选择、参数正确性和任务完成度等评测指标。
- 实现工具调用故障分类与原因分析。
- 对比不同提示词和纠错策略的执行表现。
- 生成结构化、可复现的自动化评测报告。

## 3. 核心功能

### 3.1 测试任务管理

支持创建、编辑和管理智能体测试任务。

主要功能：

- 创建和配置测试任务。
- 设置任务目标和预期结果。
- 选择参与测试的智能体。
- 配置工具及其参数约束。
- 设置测试场景和故障类型。
- 查看历史测试记录。

### 3.2 模拟工具与故障注入

构建可控的工具模拟环境，通过人为设置异常条件，测试智能体在不同故障场景下的处理能力。

支持的测试场景：

| 故障类型 | 模拟方式 | 测试目标 |
|---|---|---|
| 正常执行 | 工具正常返回结果 | 基础工具调用能力 |
| 执行超时 | 设置执行延迟或超时限制 | 超时处理能力 |
| 空结果 | 返回 null 或空列表 | 异常结果处理能力 |
| 参数错误 | 缺少参数或参数类型错误 | 参数生成能力 |
| 执行失败 | 工具返回异常状态 | 错误处理与恢复能力 |

### 3.3 智能体工具调用

实现基础 Agent 执行流程：

1. 接收用户任务。
2. 分析任务需求。
3. 选择合适的工具。
4. 生成工具调用参数。
5. 执行工具并获取结果。
6. 根据工具返回结果继续处理。
7. 输出最终任务结果。

支持不同提示词配置和纠错策略，便于开展对比实验。

### 3.4 执行轨迹记录

记录智能体完整的工具调用过程，为评测和故障诊断提供数据支持。

主要记录内容：

- 测试任务 ID。
- 智能体配置及提示词版本。
- 工具名称。
- 工具调用参数。
- 工具返回结果。
- 调用执行状态。
- 执行时间。
- 故障类型。
- 重试次数。
- 最终任务完成状态。

### 3.5 自动化评测

建立智能体工具调用能力评价体系，主要包括：

| 评测指标 | 指标说明 |
|---|---|
| 工具选择准确率 | 智能体选择正确工具的比例 |
| 参数正确率 | 工具调用参数符合预期的比例 |
| 任务完成率 | 成功完成测试任务的比例 |
| 异常恢复率 | 可恢复故障中成功恢复的比例 |
| 平均执行时间 | 完成测试任务的平均耗时 |
| 无效调用率 | 无效工具调用占总调用次数的比例 |

通过统计和分析不同指标，评价智能体在不同测试环境下的表现。

### 3.6 故障诊断

根据执行轨迹和工具执行结果，对智能体工具调用过程中的异常进行分类。

主要诊断类型：

- 工具选择错误。
- 工具参数错误。
- 工具执行超时。
- 工具返回空结果。
- 工具执行异常。
- 任务结果不符合预期。

系统根据诊断结果展示故障原因、相关执行记录和改进建议。

### 3.7 评测报告

自动汇总测试数据，生成评测报告。

报告内容包括：

- 测试任务基本信息。
- 智能体配置。
- 测试环境和故障配置。
- 工具调用统计。
- 各项评测指标。
- 故障类型分布。
- 不同策略对比结果。
- 实验结论和分析。

## 4. 系统总体架构

平台采用前后端分离架构，主要分为五个部分：

```text
                 用户
                  |
                  v
          +----------------+
          |   前端展示层    |
          |   Vue 3        |
          +----------------+
                  |
                  v
          +----------------+
          |   后端业务层    |
          |   FastAPI      |
          +----------------+
                  |
          +-------+--------+
          |       |        |
          v       v        v
       任务管理  评测引擎  故障诊断
          |       |        |
          +-------+--------+
                  |
                  v
          +----------------+
          |  Agent执行层   |
          | 工具选择/参数生成|
          | 工具调用/结果处理|
          +----------------+
                  |
                  v
          +----------------+
          |  模拟工具环境   |
          | 正常/超时/空结果 |
          | 参数错误/执行失败|
          +----------------+
                  |
                  v
          +----------------+
          |   数据存储层    |
          |     MySQL      |
          +----------------+
```

## 5. 技术栈

| 技术 | 选型 | 用途 |
|---|---|---|
| 编程语言 | Python | 核心业务和智能体开发 |
| 后端框架 | FastAPI | 后端接口开发 |
| 前端框架 | Vue 3 | 可视化管理平台 |
| UI 组件库 | Element Plus | 前端界面组件 |
| 数据库 | MySQL | 测试数据和执行记录存储 |

| 数据可视化 | ECharts | 评测数据展示 |
| 智能体模型 | 支持 Function Calling 的大语言模型 | 智能体工具调用 |
| 异步执行 | asyncio | 异步任务和超时控制 |

## 9. 项目特色

- **可控故障注入：** 通过模拟工具异常构建可重复的测试环境。
- **执行过程可追踪：** 记录智能体完整工具调用轨迹。
- **多维度自动评测：** 从工具选择、参数正确性和任务完成度等角度进行量化分析。
- **故障分类诊断：** 根据执行证据识别工具调用失败原因。
- **策略对比实验：** 支持不同提示词和纠错策略的横向对比。
- **评测结果可复现：** 保留测试配置、运行记录和评测数据。

当前项目处于设计与开发规划阶段，具体功能和技术实现将根据开发进度持续完善。
